# Shizhao Ye — Personal Website

Minimal Light academic layout with a navy background, subtle blue and teal radial lighting, and blue-to-teal CV/button gradients, inspired by the current dark appearance of https://academic-demo.netlify.app/.

Open index.html locally. Content is in index.html and appearance overrides are in custom.css. This version deliberately uses the reference's dark palette; print styles remain light. Original theme license: LICENSE-Minimal-Light.txt.

The CV label is abbreviated. Individual contributions remain in Research Experience rather than the publication list. Both email addresses appear on the site; the bundled CV PDF remains the existing export.

Asset references, navigation anchors, CSS structure, and text/button contrast were checked. Automated visual verification of the local site is blocked by the browser's file URL policy.

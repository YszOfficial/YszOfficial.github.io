# Shizhao Ye — Personal Website

My academic website, featuring research interests, publications, education, academic service, and CV.

[Visit the website](https://yszofficial.github.io/)

## Local preview

Open `index.html` in a browser. The site uses static HTML, CSS, and JavaScript; no build step is required.

Dark mode is the default. Visitors can switch themes, and their choice is remembered in the browser.

## Updating the site

| File | Contents |
| --- | --- |
| `index.html` | Profile, news, publications, experience, education, and service |
| `custom.css`, `theme.css`, `site-shell.css` | Layout, colors, typography, and navigation |
| `theme.js` | Theme selection and saved preferences |
| `assets/` | Portrait, publication figures and videos, CV, BibTeX files, and favicon |
| `hugo-panel.css`, `publication-video.js` | HuGo demonstration layout and playback |

Replace `assets/Shizhao_Ye_CV.pdf` when updating the downloadable CV. Keep asset paths relative so local previews and the hosted site use the same files.

The site is hosted on GitHub Pages.
